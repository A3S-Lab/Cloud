# A3S Cloud next documentation

`next` contains documentation under development for the next version. Its content can continue to change before merge and is not evidence that a capability has shipped or passed a delivery gate.

## Product constraints that remain fixed

- Product configuration continues to use only A3S ACL.
- Cloud continues to use PostgreSQL through A3S ORM and reuses the A3S Flow durable-operation model.
- A3S Box remains Runtime's only execution and build path.
- Gateway retains live-traffic responsibility; A3S Power retains inference-execution responsibility.
- New capabilities must enter the existing DDD boundaries without creating a parallel scheduler, control plane, or state store.

## Track development status

- Treat gate status in the [product roadmap](https://github.com/A3S-Lab/Cloud/blob/main/ROADMAP.md) as authoritative.
- Use the [repository README](https://github.com/A3S-Lab/Cloud#readme) to confirm contracts implemented today.
- Use the version selector above to return to the current `v0.1` documentation.
- Read [documentation versioning](./versioning/) for the `next` publishing workflow.
