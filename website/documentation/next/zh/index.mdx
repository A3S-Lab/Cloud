# A3S Cloud 下一版本文档

`next` 记录下一版本正在开发的文档。这里的内容可能在合并前继续调整，不能作为功能已经发布或通过交付门槛的证据。

## 不变的产品约束

- 产品配置仍只使用 A3S ACL。
- Cloud 持续通过 A3S ORM 使用 PostgreSQL，并复用 A3S Flow 的持久操作模型。
- A3S Box 仍是 Runtime 唯一的执行与构建路径。
- Gateway 保持实时流量职责；A3S Power 保持推理执行职责。
- 新能力必须进入现有 DDD 边界，不得并行创建调度器、控制平面或状态存储。

## 跟踪开发状态

- 以[产品路线图](https://github.com/A3S-Lab/Cloud/blob/main/ROADMAP.md)中的门槛状态为准。
- 通过[仓库 README](https://github.com/A3S-Lab/Cloud#readme)确认当前已经实现的契约。
- 使用顶部版本选择器返回 `v0.1` 的当前文档。
- 查看[版本管理](./versioning/)了解 `next` 的发布流程。
