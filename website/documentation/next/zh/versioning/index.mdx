# 下一版本的文档流程

`next` 是开发渠道，不是另一个产品分支。它复用同一套 Rspress 国际化、搜索和版本路由机制。

## 变更要求

1. 影响用户行为的代码变更必须同时更新 `next` 的中文和英文页面。
2. 两种语言的页面路径必须一致，标题和正文应表达同一产品契约。
3. 版本注册表是版本顺序和默认版本的唯一来源；不得再维护手写选择器或第二份版本状态。
4. 构建会分别生成每种语言和版本的搜索索引，并验证所有公开路由。

准备发布时，维护者会冻结 `next` 内容、创建新的版本快照，并把默认版本切换到该快照。旧版本路由继续保留。
