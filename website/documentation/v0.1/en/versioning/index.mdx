# Documentation versioning

A3S Cloud documentation is published by product version and language. Use the version selector to change product contracts and the language selector to move between Chinese and English within the same version.

## Current channels

| Channel | Purpose                                                                               | Chinese route | English route    |
| ------- | ------------------------------------------------------------------------------------- | ------------- | ---------------- |
| `v0.1`  | Current default, aligned with the repository's `0.1.x` series                         | `/docs/`      | `/docs/en/`      |
| `next`  | Development documentation for the next version; not evidence of a released capability | `/docs/next/` | `/docs/next/en/` |

## Publishing rules

1. A released version is an immutable snapshot except for factual corrections, security notes, and broken-link repairs.
2. Behavior intended for the next version enters `next` in the same change as its implementation and tests.
3. A new minor release freezes `next` into a version directory before the single version registry is updated.
4. Chinese and English must contain exactly the same page set in every version; build checks reject missing translations.
5. Simplified Chinese remains the default. An unprefixed documentation route never redirects according to browser language.

Versions and languages affect documentation presentation only. They do not introduce another product configuration, persistence, or control-plane mechanism.
