# A3S OS 文档

这是 **v0.1** 的默认中文文档。A3S OS 是一个可自托管的企业级 AI 操作系统：它先持久化业务意图，再通过可恢复的控制循环让工作负载、交付、可达性与运维状态收敛。

## 核心边界

- A3S ACL 是唯一的产品配置语言。
- 业务状态通过 A3S ORM 持久化到 PostgreSQL。
- A3S Flow 负责可恢复的长时操作，不引入第二套工作流机制。
- A3S Runtime 只通过 A3S Box 执行任务、服务与构建。
- Gateway 始终位于实时流量路径上；Cloud 负责生成并发布完整策略快照。
- 推理能力使用 A3S Power，并复用 Cloud 已有的调度与控制边界。
