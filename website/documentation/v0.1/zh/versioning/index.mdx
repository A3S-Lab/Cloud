# 文档版本管理

A3S Cloud 文档同时按产品版本和语言发布。顶部的版本选择器用于切换产品契约，语言选择器用于在同一版本的中文与英文页面之间切换。

## 当前渠道

| 渠道   | 定位                                      | 中文路由      | 英文路由         |
| ------ | ----------------------------------------- | ------------- | ---------------- |
| `v0.1` | 当前默认版本，与仓库 `0.1.x` 系列保持一致 | `/docs/`      | `/docs/en/`      |
| `next` | 下一版本的开发文档，不代表已发布能力      | `/docs/next/` | `/docs/next/en/` |

## 发布规则

1. 已发布版本是不可变快照，只接受事实纠正、安全说明和失效链接修复。
2. 面向下一版本的行为变更先进入 `next`，并与实现和测试在同一个变更中更新。
3. 发布新的次版本时，将 `next` 固化为新的版本目录，再更新唯一的版本注册表。
4. 每个版本的中文与英文必须包含完全相同的页面集合；构建检查会拒绝缺失翻译。
5. 默认语言始终是简体中文。访问不带语言前缀的文档路由不会依据浏览器设置自动跳转。

版本和语言只影响文档呈现，不会创建新的产品配置、持久化或控制平面机制。
